# 御灵智能 · Windows 安装包

这里只放安装包，不含源码。

## 下载安装

1. 打开右侧 **Releases**，下载最新版本里的 `YulingAgent-Setup-<版本号>.exe`。
   - 标着 **Pre-release** 的是内测版。
2. 双击安装，不需要管理员权限。装好后桌面会出现「御灵智能」。
3. 第一次打开会让你设置管理员账号，之后系统自动导入自带的技能和养牛资料（约一两分钟）。

## 使用前准备

- 需要先安装 [Ollama](https://ollama.com/download)，并在命令行执行 `ollama pull qwen3.5:4b` 下载 AI 模型（约 4 GB）。没有它也能浏览资料和技能，但不能回答问题。

## 更新与数据

- 有新版本时，在「设置 → 系统更新」里点更新即可；每个安装包都有签名，校验不通过不会安装。
- 你的数据（账号、聊天记录、上传的资料）保存在 `%LOCALAPPDATA%\YulingAgent`，更新和卸载都不会删除。
- 新版本启动失败会自动退回上一个版本。
